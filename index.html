Multilingual Safety Classifier

Two classifiers over web text (mmBERT, frozen encoder + light head): a HARMFUL scorer (SafeLM 0–5) and a SENSITIVE-topic detector. Different questions, different labels — start with the definitions.

📖 Harmful vs Sensitive — Definitions →

What we count as harmful (genuinely unsafe content) vs sensitive (merely touches a sensitive subject — war history, a death-penalty ruling, fiction). Includes the exact LLM judge prompts for each and how they differ, plus each classifier's validated performance.

FineWeb-2 — Corpus Report Card →

Per-language safety-score distribution over the full scored FineWeb-2 corpus (~5.0B documents, 1,913 languages). Adjustable severity threshold; flagged % and counts. Out-of-training languages are over-flagged (model is OOD).

DCLM-Edu — Corpus Report Card →

Safety-score distribution over the scored DCLM-Edu corpus (~1.24B English documents). English is in-distribution, so labels are reliable. Adjustable severity threshold; flagged % and counts.

FineWeb-Edu-Score-2 — Corpus Report Card →

Safety-score distribution over the scored FineWeb-Edu-Score-2 corpus (English, education-filtered web text). Distinct from FineWeb-2. A sensitive-topic detector; per-dataset validated precision lives in the Threshold Explorer. Preliminary.

Threshold Explorer →

Turn the 6-class probabilities into a binary unsafe filter: pick the score (p5 / P≥4) and drag τ to see flagged %/count, with validated sensitive-topic precision.

Examples Browser →

Read real documents at each model-predicted safety score — ~20 sampled per language & class for the 8 in-training languages (English + de/es/ru/ja/zh/fr/it). Scores 4–5 contain unsafe text.

Head Results →

Per-class / per-language metrics, confusion matrices, PR curves and binary operating points across all trained heads, on the labeled evaluation set.

Translation QA →

Side-by-side machine translations of the labeled safety data across languages, for translation-quality review.
